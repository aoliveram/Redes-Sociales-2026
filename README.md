# Redes Sociales — DCCS 2026

Repositorio del curso **Teoría de Redes Sociales 2026**, Doctorado en Ciencias de la Complejidad Social (DCCS), Centro de Investigación en Complejidad Social, Universidad del Desarrollo.

- **Profesor:** Jorge Fábrega
- **Ayudante:** Aníbal Olivera Morales
- **Formato:** 3 semanas, 6 sesiones teórico-prácticas (lunes y miércoles), R o Python
- **Evaluación:** 3 entregas semanales (25% c/u) + trabajo final integrador (25%)

## 📖 Libro del curso

Los contenidos de las ayudantías (teoría + práctica guiada en R, con datos incluidos) están publicados como libro web:

**→ https://aoliveram.github.io/Redes-Sociales-2026/**

Ahí encontrarán, para cada semana, un repaso teórico breve y un apartado aplicado reproducible que conecta directamente con la entrega semanal correspondiente.
