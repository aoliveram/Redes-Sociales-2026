4  Semana 3 — Inferencia estadística y difusión

TipConecta con

Sesión 5 (inferencia estadística en redes: QAP, ERGM e interferencia) y Sesión 6 (difusión, contagio, cascadas e intervención) · Entrega semanal 3 (25%) · alimenta el trabajo final integrador

NotaHilo conductor de la semana: estimar vs. simular

Esta es la semana donde el curso cierra el círculo. El lunes estimamos influencia a partir de datos observados (¿la similitud entre actores predice vínculos? ¿el resultado de mis vecinos predice el mío?); el miércoles simulamos difusión sobre estructuras conocidas (¿qué pasa si el contagio requiere dos vecinos en vez de uno?).

Son dos caras de un mismo problema y el aprendizaje está en la tensión entre ellas: con datos observacionales, homofilia y contagio son casi indistinguibles; en simulación podemos separarlos por construcción, pero entonces la conclusión vale para el modelo, no para el mundo. Saber qué permite decir cada camino es la competencia central de la semana.

4.1.1 Inferencia estadística en redes

(En desarrollo. Temas: dependencia entre observaciones y el problema de la independencia estadística; pruebas de permutación; QAP y MRQAP; introducción a ERGM y sus términos básicos — edges, mutuality, nodematch, triangles, gwesp; homofilia, selección, influencia y contagio; interferencia causal en redes; diferencia entre asociación, influencia e identificación causal.)

Cómo se estima influencia. Vale la pena nombrar la familia completa, aunque en clase solo lleguemos a los primeros escalones:

Supuesto sobre la red Modelo Idea
Red fija, efecto rezagado Regresión con exposición El resultado de mis vecinos en \(t-1\) predice el mío en \(t\)
Red fija, efecto contemporáneo SAR (autocorrelación de red) \(y = \rho W y + \theta X + \varepsilon\)
Red fija, conducta endógena ALAAM Como un ERGM, pero lo aleatorio es el atributo
Red y conducta coevolucionan SIENA / SAOM Separa selección de influencia con datos de panel

La exposición de red, \(E_i = \frac{\sum_j X_{ij} y_j}{\sum_j X_{ij}}\), es literalmente el mismo objeto que aparece en los modelos de umbral del miércoles. Esa es la bisagra de la semana.

4.2 Práctica guiada en R

4.2.1 A. Estimar: ¿la similitud predice vínculos?

library(igraph)

aristas   <- read.csv("datos/semana2_aristas.csv")
atributos <- read.csv("datos/semana2_atributos.csv")
red <- graph_from_data_frame(aristas, directed = FALSE, vertices = atributos)

# QAP: correlación entre la matriz de adyacencia y la de similitud
A   <- as_adjacency_matrix(red, sparse = FALSE)
sim <- outer(V(red)$disciplina, V(red)$disciplina, "==") * 1
obs <- cor(A[lower.tri(A)], sim[lower.tri(sim)])

# El nulo correcto NO es permutar celdas, sino permutar NODOS
perm <- replicate(1000, {
  idx <- sample(nrow(A))
  Ap  <- A[idx, idx]
  cor(Ap[lower.tri(Ap)], sim[lower.tri(sim)])
})
mean(abs(perm) >= abs(obs))   # valor p empírico (QAP)
library(ergm)
library(intergraph)

# El mismo resultado, ahora como modelo generativo
fit <- ergm(asNetwork(red) ~ edges + nodematch("disciplina") + gwesp(0.5, fixed = TRUE))
summary(fit)

4.2.2 B. Estimar influencia: exposición de red

# Simulamos un mundo donde SÍ hay contagio (rho = 0.5) y lo recuperamos
set.seed(3132)
n  <- 200
X  <- as_adjacency_matrix(sample_gnp(n, 0.05), sparse = FALSE)
w  <- rnorm(n)
y0 <- rnorm(n)

expo <- (X %*% y0) / rowSums(X)          # exposición: promedio de los vecinos
y1   <- -1 + 0.5 * expo + 3 * w + rnorm(n)

summary(glm(y1 ~ expo + w, family = "gaussian"))
AdvertenciaLa pregunta incómoda

Ese modelo recupera \(\rho \approx 0.5\) porque nosotros generamos los datos con contagio. Con datos reales, un \(\rho\) significativo es igualmente compatible con homofilia no observada: personas parecidas se juntan y se parecen. Ningún paquete de R resuelve esto por ti; se resuelve con diseño (panel, aleatorización, instrumentos) o se declara como límite.

4.2.3 C. Simular: contagio simple vs. complejo

library(netdiffuseR)

# Datos clásicos: médicos y la adopción de tetraciclina (1955)
data(medInnovationsDiffNet)
plot_diffnet(medInnovationsDiffNet)

# ¿Importan las semillas? Misma red, distinta estrategia
sim_random <- rdiffnet(
  n = 500, t = 10,
  seed.nodes = "random", seed.p.adopt = 0.05,
  seed.graph = "small-world", rgraph.args = list(p = 0.2),
  threshold.dist = function(x) runif(1, 0.3, 0.7)
)

sim_central <- rdiffnet(
  n = 500, t = 10,
  seed.nodes = "central", seed.p.adopt = 0.05,
  seed.graph = "small-world", rgraph.args = list(p = 0.2),
  threshold.dist = function(x) runif(1, 0.3, 0.7)
)

plot_adopters(sim_random)
plot_adopters(sim_central)
ImportantePara jugar con las variables en clase

Tres perillas y tres lecciones:

  1. Umbral. Con threshold.dist = function(x) 0.1 (contagio simple) la difusión atraviesa lazos débiles y llega lejos. Con 0.5 (contagio complejo) necesita refuerzo local: se propaga dentro de comunidades y se atasca en los puentes. Es Centola & Macy en dos corridas.
  2. Rewiring del small-world. Sube p de 0.05 a 0.5: los atajos aceleran el contagio simple y a veces frenan el complejo, porque diluyen el refuerzo local.
  3. Semillas. Con umbral bajo, semillas centrales ganan cómodamente. Con umbral alto, sembrar en un grupo cohesionado puede ser mejor que sembrar en los nodos más centrales.
